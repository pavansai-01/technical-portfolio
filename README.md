# Technical Skills & Developer Portfolio

A full-stack responsive web application showcasing technical competencies, coding profiles, an interactive resume modal, and an AI chat assistant.

## Features
- **Editorial Light Mode Interface**: Clean aesthetic with structured color borders for skills, projects, and profiles.
- **Interactive Resume Modal**: Styled resume view directly within the browser.
- **AI Chat Widget**: Interactive chat assistant integrated into the frontend.
- **RESTful Backend**: Node.js and Express backend with MongoDB database integration.

## Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose)

## Project Structure
- `frontend/`: Interactive UI, resume modal, and AI chat widget.
- `backend/`: REST APIs, routes, models, and server configuration.
